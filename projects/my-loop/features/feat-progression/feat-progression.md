# Progression System

## Key Behaviors
Players earn XP from every hex capture, distance walked, and mission completion. XP drives a level system. Daily missions provide 3 adaptive challenges per day. Achievements (30 total, 7 categories) unlock permanently at stat thresholds and award bonus XP.
