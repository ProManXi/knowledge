# Leaderboard

## Key Behaviors
City-wide daily leaderboard showing top players by area captured. Updates at 00:00 local time. Shows top 3 prominently, user's own rank, and nearby ranks. Scoped by city for MVP; neighborhood and global scopes planned for later.
